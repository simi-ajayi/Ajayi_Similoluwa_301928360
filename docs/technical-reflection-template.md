# Individual Technical Reflection

Complete this after running the work.

1. Which design decision had the largest effect on correctness or maintainability, and why?
2. What failed or behaved unexpectedly during implementation?
3. What evidence helped diagnose the problem?
4. What did you change, and how did you verify the change?
5. Which query plan result was most informative?
6. How did transaction isolation or locking affect behaviour?
7. Where was the document model more suitable than the relational model, and where was it not?
8. What would you change for a production-scale deployment?
9. What can you now explain confidently without referring to notes?
